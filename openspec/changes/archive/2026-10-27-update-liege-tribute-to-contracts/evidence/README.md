# Evidence: the liege contracts window

Pictures of the real game (1208x720, compressed). Test scenario `liege-contracts-window`, run `20261028-040953-b76e` (commit of this branch before the archive; pass). Compare with `mockups/liege-contracts-layout.html`.

| Picture | What it shows |
|---|---|
| `window-empty.jpg` | No offer: the empty text "The liege sends new contracts at the start of spring.", no cards |
| `window-three-cards.jpg` | Three cards with name, flavor text, OBJECTIVE and REWARDS items (letter box and amount), penalty badge and PICK button |
| `window-tooltip.jpg` | The mouse over an objective item. The hover text shows in the footer line (a native tooltip is not drawn, see `notes/tooltip-hover.md`) |
| `window-picked.jpg` | After a real click on PICK of the second card: Active and Discarded cards, the active panel with progress and the Complete button (grey: not ready) |
| `window-complete-ready.jpg` | Objectives met: the Complete button is ready |
| `window-after-complete.jpg` | After a real click on Complete: influence 25, silver 450, the footer says "Completed: Clear the Roads" |

Differences from the mockup (owner accepted letter boxes instead of icons, 2026-10-28): the game font and the plain brown panels, no envoy, one column of rewards in each card, and a hover text in the footer in place of a tooltip box.
