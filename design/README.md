# Design

The design documents of this repo. The user owns them. Agents read and cite them; they change them only when the user asks.

| Folder | What it holds |
| --- | --- |
| [`mod/`](mod/README.md) | The game design of the Invasion Mod: the guiding philosophy (`invasion-mod.md`), the decision log (`decisions.md`) and the trailer brief (`trailer.md`). |
| `harness/` | Reserved for a future design of the harness. Empty for now. |

The design is not a spec. Built behavior is in the living specs (`openspec/specs/`). Planned work is in the changes (`openspec/changes/`). `openspec/config.yaml` carries a short summary of the mod pillars, so every planning request sees them.
